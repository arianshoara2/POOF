# ✨ POOF

**بخوان، انتخاب کن، یاد بگیر.**

POOF یه اپ سبک و تنده برای یادگیری آلمانی — بدون اکانت، بدون سرور، بدون اینترنتِ اجباری. همه‌چیز روی دستگاه خودت می‌مونه.

🌐 **دموی زنده:** https://arianshoara2.github.io/POOF/
📱 **نسخه‌ی اندروید:** به‌زودی همین‌جا منتشر میشه

## ایده‌ی اصلی: POOF Select

وسط یه متن آلمانی، روی هر کلمه بزن — یا چند کلمه رو با انگشت انتخاب کن — تا معنی و جزئیاتش بیاد؛ بعد با یه تپ میره توی فلش‌کارت‌های شخصی‌ات، **با همون جمله و زمینه‌ای که توش دیدیش.** چون کلمه بدون زمینه زود از یاد میره.

## چی داره

- 📖 **خواندن:** متن آلمانی خودت رو بچسبون، یا مستقیم از ویکی‌پدیا مقاله بیار
- 🔍 **دیکشنری:** wort.app، Wiktionary، MyMemory و ترجمه‌ی گوگل — با کش آفلاین
- 🗂️ **کارت‌ها:** دسته‌بندی (Deck) دلخواه، جست‌وجو و ویرایش
- 🧠 **مرور هوشمند:** تکرار با فاصله‌گذاری (Spaced Repetition) — کارت‌ها سر وقتشون برمی‌گردن
- 📊 **پیشرفت:** آمار و نمودار یادگیری‌ات
- 🎨 **دو تم:** Classic (گرم و طلایی) و Snowy (آبی شبانه)
- 💾 **پشتیبان‌گیری:** خروجی و ورودی JSON — دیتات همیشه مال خودته
- 📴 **آفلاین:** به‌صورت PWA نصب میشه و بدون اینترنت هم کار می‌کنه

## تکنولوژی

یه فایل `index.html` — بدون بیلد، بدون فریم‌ورک، بدون دیتابیس. فقط HTML/CSS/JS خالص و `localStorage`.

## English

**POOF** is a lightweight app for learning German: read German texts, tap any word (or select a phrase) to get dictionary entries, and save it as a flashcard *with its original context*. Features include a Wikipedia reader, multi-source dictionary (wort.app, Wiktionary, MyMemory, Google Translate), decks, spaced-repetition review, progress stats, two themes, JSON backup, and offline PWA support. It's a single `index.html` — no build step, no backend; your data stays in the browser's localStorage.

**Live demo:** https://arianshoara2.github.io/POOF/
